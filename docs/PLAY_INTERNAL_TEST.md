# Play 내부 테스트로 설치하기

파일로 받은 APK는 알림 접근 권한 때문에 Play 프로텍트가 설치를 막습니다. Play 스토어의 **내부 테스트** 트랙으로 올리면 심사 없이 바로, 차단 없이 설치됩니다(테스터 최대 100명).

## 준비물

- 앱 번들: `jangbu-0.2.0-2.aab` (버전 0.2.0, 버전 코드 2)
- 업로드 키: 프로젝트 파일 `signing/jangbu-upload.jks` + `signing/keystore.properties`(비밀번호)
  - 앞으로 모든 업데이트를 이 키로 서명합니다. **내 PC나 클라우드 드라이브에 따로 백업**하세요.
  - Play 앱 서명을 쓰므로 이 키를 잃어버려도 Play Console에서 업로드 키 재설정을 요청할 수 있습니다.
  - 업로드 키 SHA-256: `50:09:A2:68:46:9A:BA:4C:06:E9:6E:EE:80:89:78:33:F3:F2:12:21:D6:D2:41:9A:BE:5A:79:6C:71:6F:3E:87`

## 1. 개발자 계정 (처음 한 번)

1. https://play.google.com/console 에 Google 계정으로 들어갑니다.
2. 계정 유형은 **개인**, 등록비 25달러를 결제합니다.
3. 신원 확인(신분증)과 휴대폰 인증을 마칩니다. 확인에 며칠 걸릴 수 있습니다.

## 2. 개인정보처리방침 주소

`https://ywjmoney.github.io/-/privacy.html` 를 넣습니다. GitHub Pages가 main 브랜치의 privacy.html을 보여 주므로 저장소가 공개여야 합니다(무료 계정 기준).

## 3. 앱 만들기 (처음 한 번)

Play Console → **앱 만들기**
- 앱 이름: 자동 장부 / 기본 언어: 한국어 / 앱 또는 게임: 앱 / 무료 또는 유료: 무료
- 개발자 프로그램 정책, 미국 수출 법규 선언에 체크 → 앱 만들기

## 4. 내부 테스트 올리기

1. 왼쪽 메뉴 **테스트 및 출시 → 테스트 → 내부 테스트**
2. **테스터** 탭 → 이메일 목록 만들기 → 내 Gmail 주소(폰에 로그인된 계정)를 넣고 저장
3. **새 버전 만들기**
   - 앱 서명: "Google에서 생성한 앱 서명 키 사용"(기본값) 그대로 둡니다.
   - 앱 번들: `jangbu-0.2.0-2.aab` 업로드
   - 출시명은 자동으로 `2 (0.2.0)`, 출시 노트에는 예: "결제 알림 자동 기록, 암호화 백업"
4. **다음 → 저장 → 출시 검토 → 내부 테스트로 출시 시작**
5. **테스터** 탭의 "테스터 참여 방법"에서 **링크 복사** → 폰에서 링크 열기 → **테스터 되기** → Play 스토어에서 설치

이미 파일로 설치한 v0.1이 있으면 서명이 달라 업데이트가 안 되므로, **먼저 v0.1을 삭제**하고 설치하세요(백업 파일을 먼저 저장해 두면 복원할 수 있습니다).

대시보드에 아래 항목이 필요하다고 나오면 이렇게 답합니다.
