개인정보처리방침

자동 장부 v0.2 · 시행일 2026-11-01 (초안, 출시 전 법률 검토 예정)

1. 한 줄 요약

자동 장부는 서버가 없는 앱입니다. 입력하신 기록은 사용하시는 기기 안에만 저장되며, 운영자를 포함한 누구에게도 전송되지 않습니다.

2. 처리하는 정보

  • 직접 입력하거나 붙여넣은 거래 정보: 날짜, 시간, 금액, 가맹점명, 분류, 메모, 카드 이름과 끝 4자리
  • 설정 정보: 급여일, 생활비 예산, 카드 결제일·이용기간, 고정 지출 항목
  • 결제 알림 자동 기록을 켠 경우: 휴대폰에 온 알림 가운데 금액과 "승인·결제·입금·출금" 같은 말이 함께 있는 알림의 문구와 보낸 앱 이름

붙여넣은 문자·알림의 원문은 저장하지 않고, 기기 안에서 읽어낸 결과만 저장합니다. 카드번호 전체, 주민등록번호, 계좌번호 전체는 수집하지 않습니다.

2-1. 결제 알림 자동 기록(알림 접근)

이 기능은 사용자가 앱 안내를 확인한 뒤 휴대폰 설정에서 "알림 접근"을 직접 허용해야만 동작하며, 같은 화면에서 언제든 끌 수 있습니다.

  • 결제·입출금으로 보이지 않는 알림(대화, 광고 등)은 기기 안에서 확인 즉시 버리며 저장하지 않습니다.
  • 결제 알림은 기기 안에서 금액·가맹점·날짜 등을 읽어 기록으로 만든 뒤 원문을 지웁니다.
  • 자동으로 읽지 못한 알림만 사용자가 직접 고칠 수 있도록 원문을 기기 안에 최대 30일 보관하고, 이후 자동 삭제합니다. 이 원문은 백업 파일에도 넣지 않습니다.
  • "형식 제보"를 누르면 숫자와 가려진 이름을 지운 문구를 사용자가 고른 앱(메일 등)으로 보냅니다. 보내기 전에 내용을 보여 드리며, 누르지 않으면 아무것도 보내지 않습니다.

3. 저장 위치와 보관 기간

모든 정보는 기기의 브라우저 저장소(localStorage)에 저장되며, 사용자가 앱에서 "모든 데이터 지우기"를 하거나 앱·브라우저 데이터를 삭제할 때까지 보관됩니다.

4. 제3자 제공·처리 위탁·국외 이전

없습니다. 광고 SDK, 분석 도구, 외부 API를 사용하지 않습니다.

5. 이용자의 권리

앱의 설정 화면에서 언제든 CSV 내보내기, 백업 파일 저장, 전체 삭제를 할 수 있습니다. 서버에 계정이 없으므로 별도의 탈퇴 절차는 필요하지 않습니다.

6. 앱이 요청하는 권한

  • 알림(선택): 결제 예정일을 알려 드리기 위해 사용합니다. 거부해도 모든 기능을 쓸 수 있습니다.
  • 클립보드 읽기(선택): "클립보드에서 가져오기"를 누를 때만 사용합니다.
  • 알림 접근(선택): 결제 알림 자동 기록에만 사용합니다(2-1 참고). 허용하지 않아도 붙여넣기·직접 입력으로 모든 기능을 쓸 수 있습니다.
  • 기기 재시작 후 실행(자동): 휴대폰을 껐다 켜도 예약해 둔 결제 예정 알림이 다시 울리도록 알림 예약만 복구합니다.
  • 인터넷(설치 시 표시): 개인정보처리방침 같은 외부 링크를 열 때를 위한 것이며, 장부 데이터는 어떤 서버로도 보내지 않습니다.

문자(SMS) 권한과 접근성 권한은 요청하지 않습니다.

7. 만 14세 미만

v0.1은 회원가입이 없으며, 계정 기능이 생기는 버전부터 만 14세 미만의 가입을 제한합니다.
