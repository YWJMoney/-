# 밤낮 공개 페이지

교대 근무 달력 앱 ‘밤낮’의 공개 페이지와 공개 자료만 두는 저장소입니다. GitHub Pages(`https://ywjmoney.github.io/-/`)로 나갑니다.

- `privacy/` 개인정보 처리방침, `privacy/incident/` 유출 대응 절차
- `terms/` 이용약관
- `community/` 광장 운영 규칙
- `remote/v1/` 앱이 받아 쓰는 서명된 계산 자료(요율·세액표·공휴일 등)
- `remote/firms/v1/` 회사 찾기 공개 자료(국민연금 가입 사업장 내역 등, 출처는 `meta.json`)
- `remote/card-fonts/` 장터 카드 글꼴: 공개 글꼴(SIL OFL·Apache)에서 카드에 나오는 글자만 남긴 고친 판과 그 라이선스(`remote/card-fonts/README.md`)
- `privacy.html` 살림왕 웹 가계부 처리방침(보관용)

앱과 서버 코드는 이 저장소에 없습니다.
