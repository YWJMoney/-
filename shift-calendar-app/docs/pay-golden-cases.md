## 요약

- 연장·야간·휴일 가산, 주휴수당, 최저임금 월 환산, 공휴일, 감시·단속적 근로자, 연차에 대해 예시 **32건**(주제별 1:2, 2:2, 3:4, 4:5, 5:5, 6:3, 7:3, 8:2, 9:2, 10:1, 11:3. 수치 없는 조문·판결·규칙 항목 포함)과 규칙 정리를 모았다.
- **출처를 어떻게 확인했는지 (꼭 읽을 것):** 이 세션의 네트워크 정책 때문에 직접 내려받기(WebFetch/curl)가 모든 한국 사이트에서 막혔다. moel.go.kr, law.go.kr, minimumwage.go.kr, glaw.scourt.go.kr, korea.legal, taxnet.co.kr 모두 `connect_rejected` 또는 DNS 실패였다. 그래서 아래의 모든 인용문과 숫자는 **웹 검색 엔진이 해당 URL에서 뽑아 보여준 발췌문**에서 가져왔다. 원문 페이지를 직접 열어 대조하지는 못했다. 인용문은 검색 발췌에 나온 문구 그대로 옮겼지만, 골든셋으로 확정하기 전에 사람이 원문 URL을 한 번 열어 대조해야 한다. (상태 칸: `검색발췌` = 검색 엔진 발췌로만 확인, `산술` = 출처 숫자로 내가 직접 계산.)
- 신뢰도 표기: **[1차]** 정부·법령·법원. **[1차-전재]** 1차 문서(행정해석·판결 등)를 노무법인이나 법률위키가 옮겨 실은 것. **[노무법인]** 공인노무사 법인 자료. **[2차 출처]** 블로그·계산기·언론. 언론은 정부 발표를 전한 경우에 한해 2차 출처로 썼다.
- 이 세션의 날짜는 2026-10-15이다. 2026년에 법이 바뀐 부분이 있다. 노동절·제헌절이 공휴일로 지정되었고, 근로기준법 개정(시간 단위 연차·4시간 근무 휴게 선택)이 공포되었다. 해당 항목에 반영해 두었다.

## 주제 1. 통상시급: 월 소정근로시간 209시간

### 예시 1-1. 209시간 유도
| 항목 | 값 |
|---|---|
| 출처 | [2차 출처] calcnara, glasswallet, shoplworks 계산 설명 (고용노동부 원문은 못 찾음) |
| URL | https://calcnara.com/calculators/standard-wage , https://glasswallet.com/calculate/minimum-wage/209-hours-formula , https://www.shoplworks.com/blog-insight/contractual-working-hours-209-hours-calculation |
| 입력 | 주 소정 40h + 유급주휴 8h = 48h/주 |
| 계산 | 48 × 365 ÷ 7 ÷ 12 = **208.57** → 정수로 올려 **209시간** (산술) |
| 분해 | 소정 40×365/7/12 = 173.81 ≈ 174h, 주휴 8×365/7/12 = 34.76 ≈ 35h, 174+35 = 209 (산술) |
| 상태 | 검색발췌 + 산술 |

인용 (2차): "(주 40시간 + 주휴 8시간) × 365일 ÷ 7일 ÷ 12개월 ≒ 209시간", "1개월 평균 주수 = 1년 365일 ÷ 12개월 ÷ 7일 = 4.345주".
인용 (언론, 2027 최저임금 보도): "209시간은 소정근로 174시간에 주휴시간 35시간을 더한 값" (https://www.segye.com/newsView/20260805506126 , 검색발췌).

메모: 한 블로그는 "208.86시간"이라고 적었는데, 이는 계산이 틀린 것이다. 정확히는 208.571… 이다. 주 소정근로가 40시간이 아니면 분모는 (주 소정근로시간 + 주휴시간) × 365/7/12 로 바뀐다. 이 경우 엔진이 209를 하드코딩하면 안 된다.

### 예시 1-2. 월급 → 통상시급
| 항목 | 값 |
|---|---|
| 출처 | 최저임금 월 환산액으로 역산 (주제 5의 1차 수치) |
| 입력 | 월 통상임금 2,236,300원, 월 기준시간 209h |
| 기대 출력 | 2,236,300 ÷ 209 = **10,700원/h** (산술) |
| 입력 | 월 통상임금 2,156,880원 (2026) |
| 기대 출력 | 2,156,880 ÷ 209 = **10,320원/h** (산술) |

## 주제 2. 연장근로 가산 50% (근로기준법 제56조 제1항)

### 예시 2-1. 고용노동부 임금명세서 작성 예시: 연장 16시간
| 항목 | 값 |
|---|---|
| 출처 | [1차] 고용노동부 「임금명세서」 안내 페이지 (계산방법 작성 예시) |
| URL | https://www.moel.go.kr/wageCal.do |
| 게시일 | 페이지에 표시 없음 (2021-11 시행 시점 자료로 보임) |
| 입력 | 통상시급 12,000원, 연장근로 16시간 |
| 기대 출력 | 연장근로수당 **288,000원** = 16 × 12,000 × 1.5 |
| 상태 | 검색발췌 (원문 직접 열람 불가) |

인용: "연장근로수당 288,000원 = 16시간 X 12,000원 X 1.5"
인용: "해당 월의 실제 근로한 연장·야간·휴일 근로시간 수, 통상시급, 가산율이 명시된 계산방법으로 작성해야 합니다."

### 예시 2-2. 고용노동부 예시: 연장 4시간
| 항목 | 값 |
|---|---|
| 출처 | [1차] 고용노동부 임금명세서 안내 (검색 발췌가 같은 페이지를 출처로 표시) |
| URL | https://www.moel.go.kr/wageCal.do |
| 입력 | 통상시급 12,000원, 연장근로 4시간 (야간 아님) |
| 기대 출력 | 연장근로수당 **72,000원** = 4 × 12,000 × 1.5 |
| 상태 | 검색발췌. 한 번은 페이지에 "4시간" 예시가 있다고 나왔고, 다른 검색에서는 16시간 예시만 나왔다. 원문 대조가 필요하다. |

인용: "연장근로수당 72,000원 = 4시간 X 12,000원 X 1.5"

메모: "1.5"는 연장한 시간의 기본임금 100%에 가산 50%를 더한 값이다. 월급제라도 연장 시간은 월급에 들어 있지 않으므로 1.5배 전체를 따로 지급한다.

| 기대 출력 | 야간근로수당 **24,000원** = 4 × 12,000 × 0.5 |

인용: "연장근로수당 96,000원 = 4시간 X 12,000원 X 2.0"

### 예시 3-4. 야간 고정 22:00~07:00 (간호사 나이트 등), 내가 직접 만든 테스트
| 항목 | 값 |
|---|---|

| 입력 | 통상시급 10,000원, 22:00~07:00, 휴게 1시간이 야간대(예: 02:00~03:00)에 있음, 실근로 8시간, 연장 아님 |
| 기대 출력 | 야간대 실근로 = 22~06시 8h − 휴게 1h = 7h → 야간 가산 7 × 5,000 = **35,000원**. 06~07시 1h는 가산 없음 |
| 메모 | 검색 발췌의 "야간 8시간 × 5,000 = 40,000"은 휴게를 빼지 않은 가정이다. 엔진은 휴게시간이 언제인지 알아야 한다. |

## 주제 4. 휴일근로: 8시간 이내 50%, 8시간 초과 100% (제56조 제2항), 2018 전원합의체

### 예시 4-4. 대법원 2018. 6. 21. 선고 2011다112391 전원합의체 판결 (수치 없음, 규칙 근거)
| 항목 | 값 |
|---|---|
| 출처 | [1차-전재] 판결 요지 (korea.legal, 위키문헌 판결문 PDF 페이지), 서울신문 보도 |
| URL | https://korea.legal/wiki/2011%eb%8b%a4112391/ ; https://ko.wikisource.org/wiki/%ED%8E%98%EC%9D%B4%EC%A7%80:%EB%8C%80%EB%B2%95%EC%9B%90_2018._6._21._%EC%84%A0%EA%B3%A0_2011%EB%8B%A4112391_%ED%8C%90%EA%B2%B0_%ED%9C%B4%EC%9D%BC%EC%97%B0%EC%9E%A5%EA%B7%BC%EB%A1%9C_%EC%82%AC%EA%B1%B4.pdf/7 ; https://www.seoul.co.kr/news/society/2018/06/21/20180621800045 |
| 선고일 | 2018-06-21 (다수 8 : 반대 5, 파기환송) |

인용 (해설 발췌): "휴일근로시간이 구 근로기준법 제50조 제1항의 「1주간 기준근로시간 40시간」과 제53조 제1항의 「1주간 연장근로시간 12시간」에 포함되지 않는다고 보고, … 휴일근로에 따른 가산임금과 연장근로에 따른 가산임금이 중복하여 지급될 수 없다"
인용: "2018. 3. 20. 법률 제15513호로 개정되기 전의 구 근로기준법에 관한 것이다."

엔진 메모: 같은 휴일근로 시간에는 연장 가산 50%를 또 붙이지 않는다. 8시간 이내는 1.5, 초과분은 2.0, 야간대이면 각각 +0.5이다. 휴일근로 시간이 주 40시간 계산에 들어가지 않는다는 판시는 구법 사건에 대한 것이다. 개정법(2018.3.20)은 "1주란 휴일을 포함한 7일"(제2조 제1항 제7호)로 정해 휴일근로도 주 52시간 한도에 넣는다. 그래도 가산율은 제56조 제2항이 따로 정하므로, 실무에서도 휴일근로에 연장 가산을 겹쳐 붙이지 않는다. 이 해석은 블로그 해설로만 확인했다.

### 예시 4-5. 휴일 + 야간이 겹침 (엔진 테스트용 산술)

| URL | https://www.law.go.kr/LSW/cgmExpcInfoP.do?cgmExpcDatSeq=16840&mode=2&ofiClsCd=350101 (접속 불가, 검색 결과에 제목만 확인) ; https://albup.co.kr/page/interpretation_detail.php?com_idx=13667 ; http://pmnews.co.kr/123621 ; https://leadershr.co.kr/34/?bmode=view&idx=15300019 ; https://www.delightlabor.com/information/?idx=16270172&bmode=view |
| 날짜 | 2021-03-22 |

인용 (월급제): "근로자에 대한 임금을 월급 금액으로 지급하는 경우 특별한 사정이 없는 한 월급 금액에는 유급휴일에 근무한 것으로 의제하여 그 임금도 포함된 것으로 볼 수 있으므로 … 추가적인 임금을 지급할 의무는 없다 할 것임."
월급제 근로자가 그날 일했을 때: "근로기준법 제56조 제2항에 따라 휴일근로가산수당(8시간 이내는 50%, 8시간을 초과하는 근로시간은 100% 가산)을 포함하여 지급하여야 할 것"
인용 (일급·시급제): "1일의 통상임금을 유급휴일수당으로 지급 해야 하며, 해당일에 근로를 제공하는 경우에는 휴일근로가산수당을 포함한 임금을 추가로 지급하여야 함"
비번일·무급휴일과 공휴일이 겹치는 경우: "노사 특약이나 관행이 없는 한 추가 임금 지급 의무는 없다"

**해석 및 쟁점 정리:**
- 월급제 근로자가 유급휴일에 8시간 일한 경우: 월급(유급휴일분 100% 포함)에 더해 **일한 시간에 대한 임금 100% + 가산 50% = 통상시급 × 1.5 × 시간**을 추가로 준다는 해석이 주류다. 그날 받는 것을 모두 합치면 250%가 된다. 2차 출처는 "월급제 근로자 8시간 이하 통상 임금의 150%, 8시간 초과 통상 임금의 200%"라고 적는다 (https://zuzu.network/resource/guide/holiday-work-allowance/ , https://www.heumtax.com/contents/posts/labor-day-pay-calculation).
- 질의서에 나온 "가산 50%만 추가하는가, 150%를 추가하는가"에 대해, 위 회시 문구 "휴일근로가산수당을 포함하여 지급"과 노동부 임금명세서 예시(휴일근로수당 = 시간 × 시급 × **1.5**)를 함께 보면 **150% 추가 지급**이 맞다. 다만 회시 원문의 정확한 문구("휴일근로에 대한 임금 및 가산수당"인지 등)는 law.go.kr에 접속하지 못해 확인하지 못했다.

월정 수당도 같은 비율로 나눠요. 입사 전·퇴사 뒤 날의 근무는 계산하지 않아요.

### 예시 13-4. 원 단위 끝처리 (P9, 회사 규정, G3-2)
월급 3,000,000원 ÷ 209시간 = 14,354.0669…원. 연장 10시간.
| 방식 | 계산 | 연장근로 |
|---|---|---|
| 시급을 먼저 원 단위로 (기본, 지금까지 방식) | 14,354 × 10 × 1.5 | **215,310원** |
| 줄마다 마지막에 | 14,354.0669 × 10 × 1.5 = 215,311.00 | **215,311원** |

### 예시 13-5. 단시간 초과근로 50% (기간제법 제6조 제3항, G3-3)
시급 10,320원(2026), 월~금 하루 4시간, 하루 2시간 더 일함(그날 6시간, 그 주 22시간 → 8·40시간 안).
| 회사 규칙 '단시간 50%' | 2시간 몫 |
|---|---|
| 끔 (기본) | 2 × 10,320 = **20,640원** + "단시간 근로자일 수 있어요" 안내 |
| 켬 | 2 × 10,320 × 1.5 = **30,960원** |

### 예시 13-6. 휴일대체 (제55조, G3-4)
시급 10,320원, 월~금 9~18시(휴게 1시간), 주휴일 일요일. 2026-11-08(일) 9~18시 특근, 같은 주 11/4(수)는 쉼(주는 월요일 시작).
| 처리 | 일요일 8시간 |
|---|---|
| 대체 없음 (휴일근로) | 8 × 10,320 × 1.5 = **123,840원** |
| 11/4와 미리 바꿈 (휴일대체) | 평일 근무: 그 주 40시간 안이라 8 × 10,320 = **82,560원**, 휴일근로 줄 없음 |
바꾼 날이 7일 넘게 떨어지면 주 1회 휴일 경고, 공휴일을 바꾸면 서면 합의 안내. 노동절은 바꿀 수 없어요.

### 예시 13-7. 상여 기준 금액 (G3-5)
기본급 2,000,000원, 직책수당 200,000원(통상임금), 식대 200,000원(통상임금 아님), 12월 상여 100%.
| 기준 | 12월 상여 |
|---|---|
| 기본급 | **2,000,000원** |
| 기본급+고정수당 | 2,000,000 + 200,000 + 200,000 = **2,400,000원** |
| 통상임금 | 2,000,000 + 200,000 = **2,200,000원** |

### 예시 13-8. 금액이 안 나뉜 포괄 월급 (P5·A13, 추정, G3-6)
월급 3,000,000원에 연장 20시간 포함, 월 소정 209시간: 기본급 = 3,000,000 × 209 ÷ (209 + 30) = 2,623,430.96 → **2,623,431원**, 고정 연장수당 **376,569원**(20시간). 둘 다 '추정'.

### 예시 13-9. 생산직 연장·야간·휴일수당 비과세 (소득세법 시행령 제17조, G3-7)

### 예시 13-10. 근무 종류별 유급 휴게 (G3-8)

## 확인하지 못한 것

1. **원문 직접 대조를 전혀 하지 못함.** 이 세션 네트워크에서 moel.go.kr, law.go.kr, minimumwage.go.kr, 대법원 종합법률정보, korea.legal 등 모든 한국 사이트 연결이 거부되었다 (egress `connect_rejected`). 모든 인용은 검색 엔진 발췌에서 가져왔다. 프로젝트 클라우드 환경의 Network access 설정에서 이 도메인들을 허용하면 원문을 대조할 수 있다.
2. 고용노동부 「임금명세서 작성 예시」 **전체 명세서 표**(기본급, 수당, 공제, 실수령액)의 숫자. 설명자료 PDF를 내려받지 못해 옮기지 못했다.
3. 고용노동부 페이지의 "연장 4시간 72,000원" 예시가 실제로 페이지에 있는지 (검색마다 4시간과 16시간이 다르게 나옴).
4. 임금근로시간과-653 회시의 정확한 원문, 특히 월급제 휴일근로 시 "휴일근로에 대한 임금(100%) + 가산(50%)"인지에 대한 문구.
5. 2027 최저임금 고용노동부 보도자료와 고시문 원문 (언론 보도로만 확인). 2026 최저임금 고시 원문.
