## 4. 알람 (기기 매트릭스 7가지)

폴드·삼성 폰·픽셀마다 칸을 채워요. 알람 점검 화면의 '1분 뒤 울려 보기'를 쓰면 빨라요.

| # | 상황 | 폴드 | 삼성 폰 | 픽셀 |
| --- | --- | --- | --- | --- |
| 1 | 화면이 꺼진 채 1시간 이상 둔 뒤(Doze) 제시간에 울림 | | | |
| 2 | 재부팅(잠금 해제 전 포함), 앱 업데이트, 시각·시간대 변경 뒤 울림 | | | |
| 3 | 정확한 알람 권한을 껐을 때 경고, 다시 켰을 때 정확하게 돌아옴 | | | |
| 4 | 백업에서 복원한 새 기기의 첫 실행 뒤 울림 | | | |
| 5 | 무음·방해금지, 삼성 절전 모드, 절전 앱 목록에 든 상태 | | | |
| 6 | 접은 채·펼친 채 잠금 화면 위 전체 화면 알람, 잠금 해제 없이 끄기·다시 알림 | | | |
| 7 | 조 변경·날짜별 알람·전체 끄기 직후 다음 알람이 맞음 | | | |

추가 확인:

- 알람 점검 화면의 '점검' 칸이 모두 초록이거나, 빨간 줄의 고치기 버튼이 맞는 시스템 화면을 엶
- 설정에서 앱을 강제 종료한 뒤 앱을 열면 '다음 알람 등록'이 다시 초록(자가 점검)
- 추가한 달력의 알람이 이름을 달고 울림
