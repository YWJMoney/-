# Play Console 데이터 보안 답안 (앱 1.13, 처리방침 2.0)

[PRIV-01] 처리방침 2.0(`privacy/index.html`)과 같은 내용을 Play Console › 앱 콘텐츠 › 데이터 보안에 옮길 답이에요. 통합 버전(1.13)을 올리기 전에 사용자 확인을 받고 바꿔요.

## 먼저 고칠 것

- **개인정보처리방침 주소**: `https://ywjmoney.github.io/-/privacy/`
  - 앱 1.12까지는 설정의 처리방침 링크가 저장소 루트의 `privacy.html`(살림왕 방침)을 열었어요. 1.13부터 위 주소로 바뀌어요.
  - Play Console에 적힌 주소가 `privacy.html`이면 위 주소로 바꿔야 해요.
- **처리방침 게시**: `privacy/index.html`의 게시일을 적고 main에 합치면 GitHub Pages에 올라가요.
  - 새로 수집하는 정보(앱 안 문의, ML Kit 진단 정보)가 있으니, 1.13을 출시하기 7일 전에 게시해요(방침 9항).

## 전체 질문

| 질문 | 답 |
| --- | --- |
| 필수 사용자 데이터 유형을 수집하거나 공유하나요? | 예 |
| 수집한 데이터는 전송 중에 암호화되나요? | 예 (모두 HTTPS) |
| 사용자가 데이터 삭제를 요청할 수 있나요? | 예. 앱 안에서 ‘링크 끊기’, ‘보낸 설정’ 되돌리기, 문의 지우기, ‘이 휴대폰이 보낸 정보 모두 지우기’로 지우고, 메일(yoj0790@naver.com)로도 요청할 수 있어요 |
| 계정 만들기 | 앱에 계정이 없어요. 그래서 웹 삭제 요청 주소는 필요 없어요 |
| 독립 보안 검토(MASA) | 아니요 |

Cloudflare는 운영자 대신 서버를 운영하는 처리 위탁(서비스 제공업체)이에요. 그래서 Play 기준으로는 ‘공유’가 아니라 ‘수집’이에요. Google ML Kit가 Google로 보내는 정보는 앱에 넣은 SDK가 보내는 것이므로 ‘수집’으로 적어요.

| Play 데이터 유형 | 무엇 | 필수/선택 | 목적 | 처리 방식 |

| 기기 또는 기타 ID | ① 회사 찾기와 문의에 쓰는 설치마다 만든 무작위 번호(서버에는 해시만) ② Google ML Kit가 보내는 설치마다 만든 식별자 | 선택 | ① 앱 기능, 사기 방지·보안 ② 분석 | 회사 설정·문의와 함께 삭제 |

ML Kit 항목을 ‘선택’으로 둔 이유: 명세서 사진을 읽을 때만 ML Kit가 동작해요. 사진 읽기를 쓰지 않으면 보내지 않아요.

## 수집으로 적지 않는 것 (휴대폰 안에서만 처리)

아래는 휴대폰 밖으로 나가지 않아요. 데이터 보안 양식에는 적지 않고 처리방침에만 적어요.

- 근무표, 메모, 급여·연봉·명세서 금액과 사진
- 가계부, 카드 끝 4자리, 일감 고객·장소, 매출, 미수금
- 수면 기록과 Health Connect 수면 데이터
- 캘린더에서 가져온 일정(READ_CALENDAR), 결제 알림 내용
- 메일 앱으로 보내는 메일. 이용자가 자기 메일 앱에서 보내는 것이라 앱이 수집하는 것으로 보지 않아요.
- Google 자동 백업. Android 기능이라 운영자가 수집하지 않아요.

## 1.12 답에서 바뀌는 점

| 항목 | 1.12까지 | 1.13 |
| --- | --- | --- |
| 기타 사용자 제작 콘텐츠 | 링크 이름·메모 | 회사 설정 글과 앱 안 문의 글이 더해짐 (목적에 ‘개발자 커뮤니케이션’ 추가) |
| 캘린더 일정 | 링크 근무표 | 일감 이름·시간이 더해짐 |
| 기타 금융 정보 | 세전 급여 총액 | 일감 수입·매출 합계가 더해짐 |
| 기기 또는 기타 ID | 없음 | **새로 추가** |
| 진단 | 없음 | **새로 추가** (문의 기기 정보, ML Kit) |
| 기타 앱 성능 데이터 | 없음 | **새로 추가** (알람 점검 기록) |
| 데이터 삭제 | 링크 끊기 | 보낸 설정·문의 지우기, 모두 지우기가 더해짐 |

1.12까지 Play에 실제로 어떻게 답했는지는 저장소에 기록이 없어요. ‘1.12까지’ 칸은 그때 앱이 보내던 것을 기준으로 적었어요. Play Console 화면과 대 보고 다른 곳만 고치면 돼요.

## 다른 신고

- **Health Connect**: 수면 읽기를 쓰는 이유가 ‘최근 7일 수면과 부족한 시간’에서 ‘근무별 평균 수면과 안내’로 넓어져요. Play Console의 Health Connect 권한 신고 설명도 같은 말로 고쳐요.
- **알림 접근, 정확한 알람, 전체 화면 알림**: 바뀐 것 없어요.
- **READ_CALENDAR**: 제한 권한이 아니라 따로 신고할 양식은 없어요. 처리방침 2-3항에 적었어요.
