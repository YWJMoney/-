# 밤낮 (Bamnat)

교대 근무자와 시간제 근무자를 위한 안드로이드 근무 달력입니다.
Kotlin, Jetpack Compose(Material 3), Room, AlarmManager로 만들었습니다.

## 주요 기능

**달력이 첫 화면**
- 근무 패턴을 한 번 등록하면 달력이 자동으로 채워집니다.
  - 교대 순환: 주주야야비휴, 4조 2교대, 4조 3교대 등 프리셋 제공. 직접 순서를 만들 수도 있습니다.
  - 요일 고정: 파트타임처럼 요일마다 같은 근무.
  - "오늘은 순서의 몇 번째 날인지"만 고르면 시작일이 자동으로 맞춰집니다.
- **빠른 입력**: 근무 종류를 고르고 날짜를 연달아 누르면 바로 입력됩니다. 같은 근무를 한 번 더 누르면 취소됩니다.
- 날짜를 누르면 그 날의 근무 변경, 시간 조정(이 날만), 휴게 시간, 연장 근무, 휴일 근무, 알람 끄기, 메모를 한 화면에서 처리합니다.
- 직접 바꾼 날은 점으로, 메모가 있는 날은 초록 점으로, 휴일 근무는 "휴근 4h"로 표시됩니다.

**달력 여러 개**
- 지금 달력은 그대로 두고, 알바·가족 일정처럼 달력을 더 만들 수 있습니다. 만들 때 처음 시작할 때와 같은 질문으로 근무를 정합니다.
- 달력마다 근무 종류·주기·날짜와 공유 링크가 따로이고, 달력 목록의 순서를 바꿀 수 있습니다(받은 달력 포함).

**근무시간 계산과 경고**
- 선택한 주, 이번 달 합계, 3개월 주평균을 달력 바로 아래에 보여 줍니다.
- 주 64시간 초과 시 해당 주가 빨갛게 표시되고 경고가 나옵니다.
- 3개월 주평균 52시간 초과 시 경고가 나옵니다. (기준 시간은 설정에서 변경 가능)
- 휴일 근무와 연장 근무 시간은 모든 합계에 포함됩니다.
- 계산 규칙
  - 자정을 넘는 근무(야간)는 시작한 날에 모두 셉니다.
  - 휴게 시간은 빼고 계산합니다.
  - 3개월 평균 = 해당 달과 앞의 두 달의 총 근무시간 ÷ (일수 ÷ 7).
  - 한 주의 시작은 월요일(설정에서 일요일로 변경 가능).
- 통계 탭: 월 총 근무/정규/연장/휴일 근무, 주별 막대(64시간 기준선), 최근 6개월 추이.

**알람**
- 근무 유형마다 켜고 끌 수 있고, 몇 분 전에 울릴지(직접 입력 가능)와 소리를 따로 정할 수 있습니다.
- 소리: 휴대폰의 모든 알람음·벨소리·알림음, 내 음악 파일, 무음(진동만). 미리듣기 지원.
- 점점 커지는 소리, 진동, 다시 알림 간격, 자동 종료 시간 설정.
- 잠금 화면 위에 전체 화면으로 울리고, 재부팅·시간대 변경·앱 업데이트 후에도 자동으로 다시 예약됩니다.
- 특정 날짜만 알람을 끌 수 있습니다.

**메모**
- 날짜에 붙는 메모와 일반 메모, 체크리스트(엔터로 다음 항목, 완료 항목은 아래로 모임).
- 자동 저장, 실행 취소/다시 실행, 고정, 8가지 색, 공유, 검색어 강조, 필터(고정/날짜/체크리스트/다가오는 일정).
- 삭제 후 되돌리기.
- 달력의 날짜 화면에서 한 줄 빠른 메모 입력.

**갤럭시 폴드 대응**
- 접은 화면(커버 화면)은 하단 탭, 펼친 화면은 왼쪽 내비게이션 레일과 2단 화면(달력 | 날짜 상세)으로 자동 전환됩니다.
- 접고 펼칠 때 화면이 다시 시작되지 않도록 설정해 입력 중인 내용이 유지됩니다.

**광고 자리**
- `ui/components/AdSlot.kt`에 광고 자리가 미리 잡혀 있습니다. 하단 탭 위(접은 화면) 또는 콘텐츠 아래(펼친 화면) 한 곳에만 들어가며, 달력 칸이나 버튼을 가리지 않습니다.
- 지금은 꺼져 있습니다(`AdConfig.ENABLED = false`). AdMob을 붙일 때 이 파일만 바꾸면 됩니다.

## 프로젝트 구조

```
core/   순수 Kotlin 모듈 (안드로이드 의존성 없음, JVM에서 단위 테스트)
  model/      근무 유형, 근무 패턴, 날짜별 변경 내용
  schedule/   패턴 + 변경 내용 → 날짜별 최종 근무 (ScheduleResolver), 프리셋
  hours/      주·월·3개월 근무시간과 경고 (WorkHoursCalculator)
  alarm/      다음 알람 계산 (AlarmPlanner)
  memo/       메모 모델, 체크리스트 저장 형식
app/    안드로이드 앱
  data/       Room DB, 저장소, 설정
  alarm/      알람 예약, 수신, 울림 서비스, 전체 화면 알람
  ui/         달력, 날짜 상세, 메모, 통계, 근무 유형, 패턴, 설정
```

## 빌드

Android Studio(최신 안정판)로 이 폴더를 열고 실행하면 됩니다. JDK 17 이상이 필요합니다.

```bash
./gradlew :app:assembleDebug      # 디버그 APK
./gradlew -p core test            # 근무시간·패턴·알람 계산 단위 테스트
```

## 검증 상태

- `core` 단위 테스트 36개, DB 저장 형식 테스트 5개 통과 (패턴 반복, 날짜별 변경, 휴무로 바꾼 날의 시간 제외, 야간 근무, 휴일·연장 근무 포함, 주 64시간 경계값, 3개월 평균 52시간 경계, 연도 경계, 알람 시각, 체크리스트 저장 형식 등).
- 앱 코드는 Compose Multiplatform과 안드로이드 프레임워크 클래스로 타입 검사를 통과했고, 별도 코드 리뷰에서 찾은 문제 12건(메모 중복 저장, 알림이 꺼진 상태의 알람, 휴무 전환 시 시간 계산 등)을 고쳤습니다.
- **아직 안 한 것**: 작성 환경에서 Google Maven 저장소에 접근할 수 없어 실제 APK 빌드와 기기 테스트는 하지 못했습니다. 처음 빌드할 때 라이브러리 버전 문제가 생기면 Android Studio의 안내대로 버전을 맞추면 됩니다.

## 출시 전 확인할 것 (Google Play)

- `USE_EXACT_ALARM` 권한: 알람/캘린더 앱에 허용되는 권한이라 Play Console에서 용도 신고가 필요합니다.
- `USE_FULL_SCREEN_INTENT`: Android 14부터 알람 앱에 한해 허용되며 역시 신고가 필요합니다.
- 포그라운드 서비스(`mediaPlayback`): 알람 소리를 재생하는 동안에만 사용합니다.
